- `owner_api`: transaction count, contract obligations, obligations for each of the 12 fiscal months, the top 5 recipients, PSC codes and NAICS codes, the one sub-agency, and the 5 largest place-of-performance states.

## Open questions and notes

1. **Award count endpoint.** `POST /api/v2/search/spending_by_award_count/` answers 3,203 contract awards for the slice. The snapshot holds 6,016 distinct awards with a transaction in the period, which is the ADR-0002 definition. The award search filters on an award-level date, so I left its figure out of the golden set and kept the derived count instead.
2. **Parent UEI varies within a recipient.** 13 of the 1,165 recipient UEIs have more than one `recipient_parent_uei` across their transactions. `dim_recipient` has one row per recipient, so S2 must choose a rule. The derived top-10 share resolves the reporting UEI per transaction.
3. **Missing competition code.** 5 transactions (net -47,387.44) have no `extent_competed_code`. `dim_competition` needs a row for them, or the fact join fails its audit.
4. **Competition rate.** Not derived here: it needs the competed mapping that S2 adds as a seed with a cited source. The per-code obligations in the golden set let S3b compute it once the seed exists.
5. **Agency filter by name.** The search filter rejects `toptier_code`, so the shared filter names the agency. The fetch checks that every row has awarding agency code `068`.
6. **Flaky hosts.** About one connection in two to the USAspending hosts ended with an empty reply. The client retries up to 8 times with a short backoff.
7. **Cached downloads.** The publisher answers an identical download request with the file it already generated that day. The manifest records the file name.
8. **Session setup.** The container's git identity was not the maintainer's. I set the maintainer's name and email in the repository's local config so the commits pass the CI author check. The prompt named the branch `s1-snapshot-and-golden`, so that branch is used instead of the session's default branch name.
